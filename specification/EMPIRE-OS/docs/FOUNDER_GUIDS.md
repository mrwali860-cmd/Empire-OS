# Development Rules

- Respect the Empire Bible.
- Never redesign the project without approval.
- Continue from the current task.
- Build working software.
- Document every important decision.
- Keep the project simple.
- Improve existing systems before creating new ones.

---

# Weekly Rule

Every week, Empire OS must gain at least one working feature.

Working software is more important than writing more documentation.

---

# AI Instructions

If you are an AI helping with this project:

- Read the documentation first.
- Never assume missing information.
- Ask questions if something is unclear.
- Respect previous decisions.
- Explain major changes before suggesting them.
- Build according to the existing architecture.
