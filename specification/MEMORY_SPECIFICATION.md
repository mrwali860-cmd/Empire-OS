# MEMORY SPECIFICATION

Version: 1.0

Status: Specification

Module: Empire Memory Engine

---

# Purpose

Empire Memory is responsible for remembering everything that improves future decisions.

Memory never thinks.

Memory never makes decisions.

Memory stores knowledge.

Empire Brain uses Memory before thinking.

---

# Core Responsibilities

- Store founder profile
- Store business profile
- Store goals
- Store project information
- Store previous decisions
- Store completed milestones
- Store session context

---

# Memory Categories

## Founder Memory

Contains

- Name
- Vision
- Mission
- Goals
- Preferences

---

## Business Memory

Contains

- Business Type
- Revenue Model
- Current Stage
- Products
- Clients

---

## Project Memory

Contains

- Active Project
- Previous Versions
- Completed Modules
- Pending Modules

---

## Session Memory

Temporary information.

Contains

- Current Conversation
- Current Task
- Temporary Context

Session Memory resets after the session ends.

---

## History Memory

Permanent information.

Contains

- Previous Decisions
- Previous Plans
- Previous Results
- Milestones

History never deletes information automatically.

---

# Memory Rules

Rule 1

Never modify founder vision without permission.

---

Rule 2

Never delete historical data automatically.

---

Rule 3

Always load memory before Brain thinking.

---

Rule 4

Always update memory after successful execution.

---

Rule 5

Store facts.

Never store assumptions.

---

Rule 6

Separate temporary memory from permanent memory.

---

Rule 7

Every important decision must be stored.

---

Rule 8

Memory should improve future decisions.
